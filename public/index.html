🔧 API 接口文档

        
公开下载接口

        

          

            
              

                接口
                方法
                描述
              

            
            
              

                /hosts
                GET
                
                  完整 hosts 文本；custom=false 时只包含内置 GitHub 域名。
                
              

              

                /hosts.json
                GET
                JSON 格式记录、数量和更新时间。
              

              

                /clash-hosts.yaml
                GET
                Clash YAML 域名映射。
              

              

                /health
                GET
                服务可用性与最近成功检查时间。
              

            
          

        

        

          三种格式来自同一份快照，支持 ETag
          条件请求。下载已有内容不会启动解析任务。

    2. 
          
  2. 导入 SwitchHosts 等工具，或按系统要求写入 hosts 文件。
    3. 
          
  3. 定时重新下载，以获取更新后的映射。
    4. 
        

        
域名更新模式

        
    
          
  • 手动固定：始终保留你指定的 IP。
    • 
          
  • 
            自动解析：每小时通过多源 DNS 收集并更新地址。
          
    • 
          
  • 
            本地测速：旁路由验证候选 IP 的 HTTPS
            连接，再提交实际测速结果。
          
    • 
        

        

          刷新失败会保留最近可用的记录。首页“刷新显示”读取当前快照，解析任务请在管理后台启动。
        

        
备份与恢复

        

          管理后台可导出自定义域名配置、导入 JSON 备份，或恢复最近 10
          次配置变更前的版本。
